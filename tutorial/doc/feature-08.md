# Observability

Smart Workflow integrates with [Arize Phoenix](https://github.com/axonivy-market/smart-workflow/blob/master/doc/observe/OBSERVE.md) to give you full visibility into every agent call — LLM inputs and outputs, tool invocations, token costs, and model usage. Enable it with a few configuration steps and no code changes.

---

> **This builds on [Basic Agent Setup].** The agent configuration does not change — observability is enabled at the application level and applies to all agents automatically.

---

For setup instructions, refer to the full guide in the [Smart Workflow repository](https://github.com/axonivy-market/smart-workflow/blob/master/doc/observe/OBSERVE.md).
